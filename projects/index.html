      LinkedVector-rs

      LinkedVector-rs is an experimental data structure that aims to increase cache hits when using linked lists. Nodes keep their next-pointers but live inside a contiguous Vec alongside a freelist of vacated indices, giving O(1) deletion without the cache misses of a linked list. It is benchmarked against both Vec and LinkedList.

      #Rust#Data Structures#Benchmarking
